ลำดับการตัดสินใจทุกครั้งที่ราคาขยับ

1

🔐 เช็ค License

ตรวจสอบ Account Number + วันหมดอายุ ถ้าไม่ผ่านหยุดทันที

ไม่ผ่าน → หยุด ผ่าน → ทำงานต่อ
2

📈 Trailing Stop (ทุก Tick)

เลื่อน SL ตามราคาเมื่อกำไรถึงจุดที่กำหนด ล็อคกำไรอัตโนมัติ

ทำงานทุก Tick ไม่ต้องรอแท่งใหม่
3

💰 เช็ค Daily P&L (ทุก Tick)

ถ้ากำไร ≥ 3% หรือขาดทุน ≥ 2% จาก Balance วันนั้น → ปิดทุกออเดอร์ หยุดเทรด

กำไร ≥ 3% → ปิด ขาดทุน ≥ 2% → ปิด
4

🕐 เช็คเวลา Bangkok

ตี 2–4 BKK (GMT+7) ห้ามเปิดออเดอร์ใหม่ ป้องกันช่วงตลาดเงียบ

ตี 2–4 → หยุด เวลาอื่น → เทรดได้
5

📊 อัปเดต ATR (แท่งใหม่)

คำนวณ ATR(14) ล่าสุด ใช้คำนวณ SL/TP แบบ Dynamic ตาม Volatility จริง

ATR × 1.5 = SL ATR × 3.0 = TP
6

🧭 อัปเดต Multi-TF S/R

ดึงแนวรับ/ต้านจาก H4 และ D1 มาเปรียบกับราคาปัจจุบัน กำหนด Bias

H4 S/R D1 S/R Bullish/Bearish Bias
7

📏 หา S/R Current TF

ใช้ Swing High/Low ย้อนหลัง 50–150 แท่งหาแนวรับ/ต้านหลัก

M5: Lookback 150 M15: Lookback 100

Level 1 Features
3 ระบบใหม่ที่เพิ่งเพิ่ม

ทำให้ EA ฉลาดขึ้น ปรับตัวตามตลาดได้ดีขึ้น

📐

ATR Dynamic SL

SL ไม่ตายตัวอีกต่อไป คำนวณจาก ATR(14) × 1.5 ปรับตาม Volatility จริงของตลาด ตลาดวิ่งแรง SL กว้าง ตลาดเงียบ SL แคบ

🧭

Multi-TF S/R

ดึงแนวรับ/ต้านจาก H4 และ D1 มาแสดงบนชาร์ต เมื่อ M5/M15 S/R ตรงกับ H4/D1 สัญญาณนั้นแข็งแกร่งกว่ามาก

🔍

ATR Breakout Filter

กรอง Fake Breakout แท่งที่ทะลุต้องมีขนาด ≥ 0.5×ATR ถ้าแท่งเล็ก = Fake ไม่เข้า ลด Loss จาก False Signal
